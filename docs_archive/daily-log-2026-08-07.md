## Synthesized lesson

S0 bought a real product mechanism and a painful measurement lesson. A fresh
disjoint report fold replicated a large gain twice; adaptive allocation did not
show a separable increment. The terminal confirmation did not answer the game
question because provenance and dependency repair failed before admissible
outcome parsing. The right response is neither “everything failed” nor “pretend
S0c passed”: ship the simpler replicated candidate with an explicit rollback,
close the burned evidence conservatively, and run one new collision-free
confirmation whose authority cannot be changed by a moving supervisor.
