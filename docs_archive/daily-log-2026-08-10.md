## Capture-v3 failure and the purchased lesson

The failure was not random compute noise. A legal throw can leave every player
with one card before the engine's phase classifier reaches `late`. The v3
selector treated “one card each” as sufficient for the exact-late stratum,
while its frozen quota and replay validator also required phase `late`. Seeds
`170002101` and `170007422` exposed the disagreement. The controller therefore
refused before publishing those shards, later waves never started, and none of
the six partial artifacts can enter labels.

The broader lesson is that an evidence namespace change must be propagated
through every consumer. Capture-v4 would otherwise have succeeded and then
been rejected by the label controller's hard-bound v3 packet and marker. The
v4/v5/v6 propagation proved every consumer can refuse a stale parent; v7 must
be rebound through those same heads before labels, checkpoints or REPORT
evidence exist.

## Downstream cross-commit blocker found before labels

The previously green label, training and REPORT branches were individually
correct but not jointly executable. Label runtime correctly pins its packet's
producer Git. Training and REPORT reused that same validator for an immutable
upstream parent, accidentally demanding that the old label Git equal each
newer downstream Git. Had labels completed, training would have refused before
materializing DESIGN/CALIB.

Integrated source `42e1726` keeps label execution unchanged and adds a narrow
downstream authenticator: a different upstream Git is accepted only when the
exact packet path and hashes, clean producer, runtime mode, every current label
source hash, admission geometry and all authority fields match. REPORT uses the
same boundary in controller and runtime. Training, REPORT and composition will
then freeze/run from the single integrated commit, so no further cross-Git
exception is needed. Air passes 36 focused training, 215 Stage-C and 252
Stage-C+S3c tests. This created no packet, label, checkpoint or REPORT access;
the normal external packet reviews remain the executable gates.
