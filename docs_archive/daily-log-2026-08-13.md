## Overnight engineering lessons

- **Historical evidence and current code are different identities.** A
  behavior-preserving optimization legitimately changes source-derived ballot
  hashes. The right repair is to keep old confirmation receipts immutable and
  add a reviewed compatibility statement for current code—not silently rewrite
  history or weaken drift checks.
- **Architecture portability must be explicit.** The S5 diagnostic was correct
  but bound to an ARM native binary. The x86 wrapper preserves the historical
  parent, pins the new native/ballot contract, and replays the same score-free
  decisions before it can consume the original one-shot authority.
- **Profile hypotheses still need end-to-end timing.** Replacing `sorted` with
  `min` looked attractive in a profile but produced no whole-round gain and was
  dropped. Preparing a sampled world once targets measured duplicate work and
  produced a small reproducible exact-head gain while preserving transcripts.
  A larger cache result stayed unpublished when adversarial tests found stale
  values after legal public-object mutation and changed trump ordering; the
  safe repair was slower, so it was discarded rather than rationalized.
- **The fleet stays hypothesis-driven.** Mini, Air and strength Cloud remain on
  T4, Pair and S4. The dedicated x86 host performs bounded engineering only
  while S5 recovery authority remains closed.
- **Tests must not borrow scored-host cores.** A helper unintentionally started
  two pytest processes beside T4 on Mini. They were identified and stopped
  after roughly two CPU-core-minutes; no evidence was written, no outcome was
  opened and T4 stayed healthy. A later PR #94 broad suite similarly escaped
  its command session for under 45 seconds on one core; only its exact process
  tree was stopped and the complete suite moved to the idle x86 host. Broad
  tests now stay off live scored hosts.
- **Exercise host provenance before spending one-shot authority.** PR #89 and
  the PR #93/#94 controllers all encoded systemd's invocation symlink
  backwards. PR #89 refused before evidence or an arm; both controllers were
  repaired before execution, with synthetic inverse-shape regressions and a
  real-host unit-name→InvocationID witness. PR #93's first freeze also refused
  before output on an ignored duplicate native build shadow; moving that
  rebuildable directory outside the checkout let the exact shadow-free packet
  freeze and verify without consuming capacity execution authority.
- **A documented marker convention is not an executable gate.** PR #74
  repeated INC-17 because the wrapper could not distinguish an implementer's
  byte-perfect request from a reviewer attestation. The old admission is spent;
  recovery requires a distinct attestation prefix, pinned review provenance,
  one canonical admission path and explicit retry authority.
- **Close dead execution code, retain reusable science.** After the S5 refusal
  repair PASSed, PRs #74/#76 were closed while PR #70's diagnostic source was
  retained. PR #55's exact preservation delta then PASSed merge-readiness; the
  reviewed #55→#60→#61→#72 stack must merge in that order.
