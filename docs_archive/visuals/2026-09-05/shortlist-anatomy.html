How the full-legal shortlist hands work to MC-LCB

W32 is a root-selection screen: a complete-world model ranks every legal submitted action on 32 shared sampled worlds, then hands a bounded ballot to the existing production search. It is a proposal mechanism, not a replacement search or a recursive PUCT tree.

The ranking branch enumerates all legal actions, applies each action in a compatible sampled world, completes the current trick with the heuristic, and ranks the resulting complete-world values. The heuristic incumbent is always retained. Forced singleton decisions and the production tractor-lock bypass are outside this search-path illustration; W32 disables that bypass when enumerating its legal population.

The inherited final search uses N30 shared selection worlds and a separate fresh R300 paired report for the nominated challenger and incumbent. A complete report whose paired lower confidence bound reaches zero may accept the challenger; otherwise the incumbent remains. Uniform selection is the reference; opt-in adaptive allocation changes only how root selection work is allocated and does not change production or the default.
