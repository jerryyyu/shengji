# Moderation list for the chat filter (chat_filter.py): words masked with
# asterisks in every free-text chat line and in guest names, and refused as an
# account's display name. Kept modest and conservative on purpose: a word that
# is also an ordinary word in a card game's chat stays off the list.
#
# Latin-script lines are whole words, matched case-insensitively after the
# leetspeak folds (0 o, 1 i, 3 e, @ a, $ s) and with any letter
# allowed to repeat ("fuuuck"). A word is never matched inside a longer word,
# so "class", "assassin" and "Scunthorpe" are untouched. Because letters may
# repeat, an entry must not be an ordinary word once its letters are doubled
# ("asses" would catch "assess", so it is not listed).
#   word     the word alone
#   word*    the word or the word with one common ending (s, er, ing, ed, y,
#            head, face, ...); only for words whose endings make no ordinary word
#
# Chinese lines are phrases, matched anywhere in the text (Chinese has no
# spaces between words), so only phrases with no ordinary reading are listed.
#   =字      only when it stands alone, not next to another Chinese character
#            (操 alone, but not 体操, 操作 or 曹操)
#   字!xyz   not when followed by any of the characters x, y, z
